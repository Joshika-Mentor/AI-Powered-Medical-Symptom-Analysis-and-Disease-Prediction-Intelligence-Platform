BACKEND UPLOAD

Upload this `backend` folder to your Rohitha GitHub branch.

Structure:
backend/
  app/
    main.py
    auth.py
    config.py
    db.py
    schemas.py
    knowledge.py
    services/
    ml/
  requirements.txt

The original `app` package structure is intentionally preserved because the Python code uses imports such as `from app.db import ...`.

Frontend (`app/static/dashboard.html`) is intentionally left out for now.
